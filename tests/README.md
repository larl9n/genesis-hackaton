# Проверки

На этапе каркаса предметных тестов нет: генератор, среда и оценщик ещё не реализованы.

Будущая структура:

- `unit/` — деньги, FX, валидация и сопоставление находок.
- `integration/` — генерация, инструменты и полный эпизод.
- `adversarial/` — обход награды, malformed input, утечки и бюджеты.
- `reproducibility/` — одинаковые seed и действия, перестановки и переименование ID.

Критерии и обязательные случаи описаны в [docs/VALIDATION.md](../docs/VALIDATION.md). CI пока выполняет только smoke-проверки каркаса.
