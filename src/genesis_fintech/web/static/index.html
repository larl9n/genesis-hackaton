    // ПРИНЦИП ОЦЕНКИ
    Хороший ответ можно проверить.
    Genesis — синтетическая среда для исследования финансового аудита. Агент изучает документы и отправляет структурированные находки. Оценщик проверяет тип ошибки, затронутые записи, сумму, валюту и достаточность доказательств.
    F1 учитывает найденные ошибки, пропуски и ложные тревоги. За лишние действия предусмотрена небольшая стоимость. Повторные обвинения не дают дополнительных баллов.
    В этой демонстрации работают алгоритмы сверки, а не обученная нейросеть. Локальная веб-панель запускает доверенные политики; контейнерный режим оценки доступен отдельно через CLI.
