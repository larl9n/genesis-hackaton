# Интерфейс Genesis

UI встроен в Python-проект: HTML/CSS/JavaScript без Node, npm, сборки и внешних runtime-библиотек. Дизайн адаптирован из пользовательского `hyperstudio.org-DESIGN.md`: canvas #080808, общие rails 850px, квадратные панели, песочные mono-подписи, двойные серебристые кнопки и белая упорядоченная dot-matrix композиция.

## Открыть

В обычном терминале из корня проекта:

```bash
.venv/bin/python -m genesis_fintech serve
```

Открыть http://127.0.0.1:8765. Для другого порта: `serve --port 8787`. Сервер привязывается только к loopback. Это локальная демонстрация, не публичный production-сервис.

Можно открыть `src/genesis_fintech/web/static/index.html` непосредственно в браузере. Тогда интерфейс честно показывает записи трёх настоящих прогонов seed42, политика и seed зафиксированы. Кнопка выбирает сохранённый пример текущего сценария и не имитирует выполнение нового аудита. Через локальный сервер доступны произвольный допустимый seed и все три обычные политики.

## Пользовательский путь

1. Краткое объяснение среды и четыре возможности.
2. Выбор взаимодействующих/независимых ошибок либо чистой компании, seed и политики.
3. Запуск сверки; на время запроса кнопка блокируется, ошибки не уничтожают прошлый результат.
4. F1, TP/FN, ложные тревоги, шаги и награда; находки открывают диалог со свидетельствами.
5. Вкладка траектории показывает реальные запросы. Экспорт JSON сохраняет текущий результат с явным признаком записи или нового прогона.
6. Светлая детальная панель связывает вывод с документами. Полное описание подхода доступно отдельно от декоративно затухающего текста.

Метрики и суммы вычисляет существующий Python-движок. UI не предоставляет скрытый truth/provenance. Доказательства собираются исключительно из записей, полученных политикой через инструменты. Список гипотез не выдаётся за список истинных ошибок при наличии FP; пропуски и truncation отображаются отдельно.

Локальный UI использует доверенные in-process политики. Это не контейнерный оценочный запуск и не обучение нейросети. Изолированная оценка остаётся командой `run-policy`; UI не расширяет её привилегии и не предоставляет произвольные команды.

## API и ограничения

- `GET /api/status` — доступность локального режима и версия.
- `POST /api/run` — строго `{seed, scenario, policy}`; seed 0..2147483647, три сценария, три фиксированных политики. Не допускает oracle, произвольные конфиги или пути.
- До 4 KiB входных данных, до двух одновременно выполняемых запросов; timeout чтения 5 секунд. Это не полноценная защита публичного сервера от DoS.
- Строгие Host/Origin, только application/json, без CORS-разрешений сторонним сайтам.
- Static разрешён только явным списком. Нет endpoint для файлов проекта, private или произвольной директории.
- CSP, nosniff, frame denial; динамические данные вставляются через textContent, не HTML.
- Все ассеты локальные. Платные Aeonik/Input не включены; используются font stacks Aeonik/Inter и Input/IBM Plex Mono с системным fallback. При отсутствии этих шрифтов внешний вид использует системный grotesk/mono.

## Доступность и адаптивность

Один h1, landmarks, labels полей, skip-link, видимый focus, клавиатурное переключение tabs, native dialog с Escape и возвратом фокуса, live-status результата, reduced-motion. При узком экране сетки складываются в колонку, панели и кнопки остаются в rails. Визуальные выводы относятся только к проверенным viewport и браузерам.

## Воспроизвести ассеты

```bash
PYTHONPATH=src .venv/bin/python scripts/build_ui_samples.py
.venv/bin/python scripts/build_ui_art.py
```

`samples.js` хранит сериализованные view-модели реальных прогонов. Тест сравнивает их с новым выполнением движка. SVG содержит 6063 упорядоченные точки, рассчитанные по двум поверхностям; это собственная графика без копирования студийных изображений.

## Проверено

- 7 новых локальных функциональных тестов: движок/метрики, evidence, отсутствие truth, честные отрицательные результаты, точное совпадение записей, параметры, маршруты/Host/Origin/size/content-type.
- Восьмой тест использует настоящий loopback HTTP. В текущей песочнице bind запрещён, поэтому локально тест пропущен; при CI запрет bind является ошибкой, а не skip.

- JavaScript app.js и samples.js синтаксически проверены Node VM.
- В Chrome открыт локальный index.html; просмотрен первый экран, AX подтверждает заполненные метрики, все четыре находки, доказательства и подписи. ## Исследовательский стол

По отдельному поручению пользователя добавлены четыре компактные функции без новых зависимостей:

- Граф в диалоге доказательств: узлы — только полученные записи; линии — явные invoice/payment references. Курсы без явной ссылки остаются отдельными узлами. Клик или Enter на узле раскрывает запись; линия не утверждает правильность обвинения. На узком экране граф прокручивается горизонтально.
- Сравнение трёх обычных политик на одинаковых seed/scenario: TP/FP/FN, F1, награда, шаги. Oracle не включён. В файловом preview доступны явно помеченные реальные записи seed42 из comparisons.js; сервер выполняет новый прогон.
- Ручной аудит на локальном сервере: выбор таблицы и страницы по20, получение записи/документа по ID, калькулятор, составление до30 находок и отправка. Пустой ответ допустим. 100 действий и60 секунд с reset; истечение времени даёт truncated и пустую отправку. Награда0 и отсутствие metrics до завершения, затем итоговая оценка. Суммы в форме задаются целыми minor units. Собственный аудит экспортируется в JSON с начальными наблюдениями и переходами.
- HTML-отчёт последнего результата алгоритма: метрики, находки, полученные записи, траектория и, если запускалось, отдельно подписанное сравнение. Файл автономный, без scripts/внешних ресурсов; его можно распечатать или сохранить как PDF средствами браузера. Все значения вставляются через textContent.

Новые маршруты POST /api/compare, /api/manual/start, /api/manual/step имеют тот же Host/Origin/JSON контроль. Manual sessions — случайные capability tokens в памяти, максимум8, cleanup через75 секунд, отдельная блокировка каждого эпизода. Final/expired session повторно не используется. Обычные запросы до4 KiB, только manual/step до64 KiB; общий лимит двух HTTP-вычислений сохранён. Перезапустите serve после обновления исходников. Это локальный доверенный интерфейс, не внешний многопользовательский сервис.

Пять новых функциональных тестов покрывают сравнение/recordings, чистый ручной аудит и документы, отсутствие промежуточного score/truth, независимость sessions, timeout, capacity/expiry, origin/frames. Настоящий HTTP test в CI дополнен compare/start/submit. Локальная регрессия181:176 passed,5 skips; четыре JS-файла синтаксически проверены Node VM. При повторном native Chrome QA браузер вернул серый screenshot и недоступное содержимое после reload; визуальная приёмка новых элементов не подтверждена. Ранее подтверждённая косметика остаётся отдельной проверкой. Финальный CI новых функций проверяется отдельно.
