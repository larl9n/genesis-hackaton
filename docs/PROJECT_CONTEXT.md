## Что требуется от конечного проекта

- Воспроизводимая RL-ready среда для ИИ-аудитора, а не банковское приложение.
- Сначала согласованная история компании, затем документы и причинно внесённые ошибки.
- Четыре независимо настраиваемых семейства: дубли счетов, распределение платежей, FX/date mismatch, cutoff.
- Два взаимодействующих сценария, чистые компании и корректные отвлекающие случаи.
- Открытые manifest, policy, ledger, invoices, payments, fx; приватные truth, provenance и seed.
- `reset(seed, config)` и `step(action)`; инструменты list_records, get_record, get_document, calculator, submit.
- Предложенные лимиты: 100 шагов с отправкой, 50 строк на страницу, 60 секунд на эпизод.
- Сопоставление находок один к одному по типу, IDs, сумме, валюте и полному набору доказательств.
- Общая награда: `clip(2*F1 - 1 - 0.002*inspection_steps, -1, 1)`. Повторы — FP; без промежуточных подсказок о корректности.
- Отдельный процесс политики и проверяемая изоляция от truth, файлов хоста и сети. Одних модулей/процессов недостаточно.
- Random, reconciliation, flag-all и evaluator-only oracle; 10 train + 10 dev, траектории, тесты, отчёты, README, лицензия, фиксированные зависимости и контейнерные инструкции.
- Обучение весов, GPU и платные API необязательны. Реальные финансовые/персональные данные не используются.

## Возврат к чату

Установлен `codex-cli 0.169.0`; синтаксис проверен через `codex resume --help`.

Точный идентификатор текущего чата: `01a1d536-8ebb-7251-9871-1d3b095ddd0b`.

```bash
codex resume 01a1d536-8ebb-7251-9871-1d3b095ddd0b -C /Users/zhopa/genesis-fintech-env
```

Выбор из сохранённых сеансов: `codex resume --all`. Команда `codex resume --last` выбирает последний сеанс, который может оказаться другим чатом.

Эти команды предназначены для обычного терминала. Возобновление зависит от наличия локального сохранённого сеанса. Если открыть новый чат в папке проекта, AGENTS.md направит к этой сводке.
