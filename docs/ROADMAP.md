# Этапы реализации

Распределение задач между людьми не фиксируем. Дедлайн — до 20 ноября 2026 года; внутренний ориентир сдаваемой версии — 19 ноября. Точное время приёма уточняется.

| Этап | Результат | Критерий готовности |
| --- | --- | --- |
| 0. Каркас — текущий этап | Документация, структура модулей, CLI, конфигурация и CI | Файлы согласованы, команды smoke-проверки работают на целевом Python |
| 1. Один полный эпизод | Корректные данные, два семейства ошибок, инструменты, scorer и простая политика | Одна команда создаёт эпизод, записывает действия и выдаёт оценку |
| 2. Полнота сценариев | Все четыре семейства, два взаимодействия, чистые компании и decoys | Каждый сценарий имеет доступные доказательства и независимую проверку |
| 3. Надёжность | Изоляция, бюджеты, adversarial и reproducibility проверки | Нет утечек; повторы и некорректные ответы не обходят оценку |
| 4. Оценка и артефакты | Четыре политики, 10 train + 10 dev, траектории, сравнительный отчёт | Повторяемые результаты с версиями и конфигурациями |
| 5. Сдача | Лицензия, фиксированные зависимости, контейнерные инструкции, README и демо | Полный прогон из чистого окружения и проверка комплекта |

## Ближайший технический шаг

На одном минимальном примере зафиксировать runtime-схемы manifest, ledger, invoice, payment, truth и findings. Определить канонизацию ID, ожидаемые суммы по семействам ошибок, округление и evidence matching. Затем реализовать корректный генератор чистой компании и независимую проверку её равенств.

## Приоритеты

Сначала сквозной работающий контракт, затем полнота сценариев и защита оценивания. Дополнительный сайт, обучение модели и экспериментальную награду рассматриваем после обязательного объёма. Дизайн сайта не блокирует работу.

## Текущее ограничение среды разработки

На старте доступен Python 3.9.6, а нужен целевой Python 3.11. Первоначальная DNS-ошибка устранена включением сети: GitHub отвечает HTTP/2 200, `git ls-remote origin` выполняется успешно. GitHub-плагин также подключён. Проверенный запуск на 3.11 и фактическая публикация файлов пока не выполнены; терминальная авторизация записи ещё не проверена.
