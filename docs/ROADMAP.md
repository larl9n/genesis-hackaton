## Ближайший технический шаг

Комплект 0.5.0 прошёл CI. Блок 0.6.0 добавляет обучающий JSONL и проверку по актуальному черновику; подробности — SUBMISSION.md и TRAINING.md. Это завершающая приёмка обязательного кейса, не новый сайт или обучение модели. Development-режим не выдавать за OS-изоляцию.

## Приоритеты

Сначала сквозной работающий контракт, затем полнота сценариев и защита оценивания. Дополнительный сайт, обучение модели и экспериментальную награду рассматриваем после обязательного объёма. Дизайн сайта не блокирует работу.

## Текущее ограничение среды разработки

Проверки каркаса прошли на Python 3.11 в [GitHub Actions](https://github.com/larl9n/genesis-hackaton/actions/runs/43464208929) и локально в `.venv` на Python 3.11.18. Системный Python 3.9.6 не менялся. README и каркас опубликованы в main. DNS-ошибка устранена, запись через GitHub-плагин работает. Терминальная авторизация для push отдельно не проверена.
