# Проверка качества

Статус: 118 тестов для схем, Decimal, чистой истории с FX/возвратами/границами, четырёх инъекций и двух композиций, независимой истины, scorer, development reset/step, файлов и CLI. `make check` запускает весь набор вместе с проверкой Python, компиляцией и пятью конфигами. OS-изоляция и полная упаковка остаются будущими проверками.

Текущие результаты и команды — в [CHECKPOINTS.md](CHECKPOINTS.md). Чистые FX/граничные книги и обе формы полных сценариев проверены на 50 seed; возвраты — на 20, неверная FX-дата — на 20. Есть 16 комбинаций семейств и ручные примеры FX, обратного cutoff и возврата, не созданные генератором. Проверены доказательства, FP/повторы/flag-all/abstention, ID/order, лимиты, закрытая награда и полный oracle demo. Это не тест реальной изоляции внешнего процесса.

## Матрица предметных проверок

| Область | Обязательные случаи | Что подтверждаем |
| --- | --- | --- |
| Генерация | Чистая история до инъекций, четыре типа ошибок, два взаимодействия, валидные отвлекающие случаи | Данные согласованы, изменения причинны, truth проверяется по записям |
| Деньги и FX | Minor units, разные валюты, округление и граничные даты | Нет float-сравнений и скрытого смешения валют |
| Контракт | reset, пагинация, неизвестные ID/actions, ошибочный JSON, калькулятор | Ограниченный детерминированный результат; нет исполнения кода |
| Завершение | Последний шаг submit, исчерпание шагов, тайм-аут, повторная отправка | Корректные terminated/truncated, пустая отправка при truncation |
| Matching | Верный тип/ID/сумма/валюта, полные и неполные доказательства | TP только за обоснованный вывод; сопоставление один к одному |
| Награда | Oracle, abstention, false alarms, duplicates, flag-all | Нет кредита за повторы; ложные выводы ухудшают результат |
| Изоляция | Файлы, импорты, наблюдения, info, ошибки, reward, сеть | Политика не получает закрытые данные и не меняет оценщик |
| Воспроизведение | Одинаковые seed/config/actions; перестановки и новые ID | Точный повтор; содержательно эквивалентные пары сохраняют оценку |
| Упаковка | Чистое окружение, отсутствие сети при оценке, бюджеты | Запуск по README в заявленных ресурсах |

## Обязательные свойства награды

- Поддержанные правильные находки лучше воздержания на ошибочных данных.
- Воздержание лучше ложных тревог на чистых данных.
- Повторы не дают дополнительного TP и учитываются как FP.
- Массовая отправка догадок не обходит ограничения и штрафы.
- Экономия шагов меняет оценку меньше, чем существенное ухудшение F1.
- Ошибочные валюта, сумма, affected IDs или доказательства не получают TP.

## Сравнение политик

Все политики прогоняются на одном наборе эпизодов. Random использует отдельный фиксированный seed политики. Reconciliation и flag-all не имеют доступа к truth. Oracle запускается только оценщиком и проверяет потолок награды, а не качество агента.

Отчёт включает precision, recall, F1, return, шаги и runtime. Описываем конкретные случаи сбоев baseline. Нельзя делать вывод об улучшении модели по одному oracle или без контролируемого сравнения.

ТЗ предлагает 20 закрытых эпизодов и 20 парных проверок организаторов. Команда может создать свои отложенные проверки, но они не заменяют официальный стенд и не называются его результатами.

## Ресурсный ориентир

По черновику: Python 3.11, 2 CPU, 4 GB RAM, без GPU, пакет до 1 GB, до 60 секунд и 100 шагов на эпизод. Замерять фактическое потребление, сохранять конфигурацию окружения и перепроверить финальный регламент перед сдачей.
